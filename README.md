# Битва колод (Android, Kotlin + Jetpack Compose)

Карточная игра против бота: 3 колоды по 10 карт (Монстры, Мифические существа, Люди),
5 карт в руке, до 5 карт на поле, 3 раунда с выбором баффов и финальная битва.

## Как запустить
1. Установите Android Studio (Koala или новее).
2. `File → Open` и выберите эту папку. Дождитесь Gradle Sync.
3. Запустите на эмуляторе или телефоне (Android 7.0+, minSdk 24): кнопка ▶ `app`.

## Структура
- `app/src/main/java/com/cardgame/core/` — правила игры без Android-зависимостей
  - `Model.kt` — карты, эффекты, баффы, снимки состояния для интерфейса
  - `Cards.kt` — все 30 карт и генератор вариантов баффов (правьте цифры здесь)
  - `Game.kt` — фазы партии, порядок атак, урон, эффекты, бот
- `app/src/main/java/com/cardgame/ui/` — интерфейс (Compose) по макету
  - `Components.kt` — карта, рука «веером», панель героя
  - `Screens.kt` — меню, экран боя, окно выбора усиления, итоги
  - `GameViewModel.kt` — связка движка с экраном, анимация боя

## Где что менять
- Баланс и эффекты карт: `Cards.kt` (stats `atk`/`def`, тип и параметры эффекта).
- Картинки карт: сейчас вместо арта используется emoji (`emoji` в `CardTemplate`);
  для настоящих картинок замените `Text(card.emoji…)` в `BattleCard` на `Image(...)`.
- Размеры поля/руки/числа раундов: константы в начале `Model.kt`.
