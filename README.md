# Битва колод (Android, Kotlin + Jetpack Compose)

Карточная игра против бота: 3 колоды по 10 карт (Монстры, Мифические существа, Люди),
5 карт в руке, до 5 карт на поле, 5 раундов с выбором баффов и финальная битва (в финале рука добирается только до 3 карт).

## Как запустить
1. Установите Android Studio (Koala или новее).
2. `File → Open` и выберите эту папку. Дождитесь Gradle Sync.
3. Запустите на эмуляторе или телефоне (Android 7.0+, minSdk 24): кнопка ▶ `app`.

## Структура
- `app/src/main/java/com/cardgame/core/` — правила игры без Android-зависимостей
  - `Model.kt` — карты, эффекты, баффы, снимки состояния для интерфейса
  - `Cards.kt` — все 30 карт и генератор вариантов баффов (правьте цифры здесь)
  - `Game.kt` — фазы партии, порядок атак, урон, эффекты, бот
- `app/src/main/java/com/cardgame/ui/` — интерфейс (Compose) по макету
  - `Components.kt` — карта, рука «веером», панель героя
  - `Screens.kt` — меню, экран боя, окно выбора усиления, итоги
  - `GameViewModel.kt` — связка движка с экраном, анимация боя

## Где что менять
- Баланс и эффекты карт: `Cards.kt` (stats `atk`/`def`, тип и параметры эффекта).
- Картинки карт: сейчас вместо арта используется emoji (`emoji` в `CardTemplate`);
  для настоящих картинок замените `Text(card.emoji…)` в `BattleCard` на `Image(...)`.
- Размеры поля/руки/числа раундов: константы в начале `Model.kt`.

## Сетевая игра

В главном меню три режима:

1. **Одиночная игра (бот).**
2. **⚡ Быстрый поиск** — через сервер на ПК (`CardGame_Server/server/server.py`). Приложение само
   находит запущенный сервер в Wi‑Fi сети (UDP 8767); кнопка активна, только пока сервер найден.
   Если автопоиск заблокирован роутером — введите IP компьютера вручную (он запоминается).
3. **Игра по одной сети** — без сервера. Один телефон нажимает «Создать игру», второй —
   «Подключиться» и выбирает первого в списке (или вводит его IP). Работает в общей Wi‑Fi сети и
   когда один из телефонов раздаёт точку доступа. Порты: TCP 8766, UDP 8767.

### Как устроена синхронизация
Обе стороны запускают одну и ту же партию (общий сид), а по сети передаются только ходы:
выставил/сбросил карту, закончил ход, выбрал цель, выбрал бафф. Расстановка идёт по очереди
(в нечётных раундах первым ходит создатель игры/первый игрок, в чётных — второй), бой — по
порядку атак. К каждому ходу прикладывается контрольная сумма состояния; если у двух устройств
она разошлась, партия прерывается с сообщением, а не продолжается «вразнобой».
Логика режима — `core/Game.kt` (`pvp = true`), сеть — пакет `network/`.
